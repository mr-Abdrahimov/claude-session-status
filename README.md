# session-status

Мод для Claude Code (терминал и вкладка Code в десктоп-приложении): показывает статус чатов.

**Строка над полем ввода** в каждой сессии:

```
● работает 3м · Opus 5.5 · high · агентов 2 (sonnet×2) · main a1b2c3d «fix: …» 5 минут назад ✓ сборка прошла (Deploy)   Все сессии
```

- идёт ли работа: `● работает`, `◐ ждёт разрешения`, `○ готов`, `◌ закрыта`, и сколько длится состояние;
- модель и уровень effort (low / medium / high / xhigh / max) основной сессии;
- сколько субагентов работает прямо сейчас и на каких моделях;
- ветка и последний коммит, сколько коммитов не запушено, статус сборки на GitHub
  (GitHub Actions, а если их нет — commit statuses, например Vercel).

**Панель «Сессии»** (`/sessions` или кнопка «Все сессии»): все сессии на этой машине, сгруппированные
по репозиторию, у каждого проекта — последний коммит, его сборка и ссылка на неё, у каждой сессии —
статус, модель, effort и список активных агентов с их моделями.

## Установка

В терминальной сессии Claude Code:

```
/plugin install session-status --marketplace mr-Abdrahimov/claude-session-status
```

Ответьте `y` на «Add marketplace?» и выберите область user — мод заработает во всех сессиях,
включая сессии, которые запускает десктоп-приложение.

Из шелла:

```bash
claude plugin install session-status --marketplace mr-Abdrahimov/claude-session-status
```

В десктоп-приложении: «+» рядом с полем ввода → Plugins → Add marketplace `mr-Abdrahimov/claude-session-status` → Add plugin.

## Что нужно

- `git`;
- `gh`, вошедший в GitHub (`gh auth login`) — для статуса сборок. Без него мод покажет всё, кроме CI.

## Команды

- `/sessions` — открыть панель всех сессий;
- `/session-band` — скрыть или показать строку над полем ввода.

## Как это устроено

Каждая сессия раз в 15 секунд (и сразу при смене состояния) пишет свою запись в
`~/.claude/session-status/<id сессии>.json`; панель читает все записи. GitHub опрашивается раз в
минуту и через 5 секунд после конца каждого хода (после коммита или пуша). Сессия, которая не писала
больше 45 секунд, показывается как закрытая; записи старше 3 дней не показываются.
