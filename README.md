# session-status

Мод для Claude Code (терминал и вкладка Code в десктоп-приложении): показывает статус чатов.

**Строка над полем ввода** в каждой сессии:

```
● работает 3м · Opus 5.5 · high · агентов 2 (sonnet×2) · main a1b2c3d «fix: …» 5 минут назад ✓ сборка прошла (Deploy)   Сессии проекта
```

- идёт ли работа: `● работает`, `◐ ждёт разрешения`, `○ готов`, `◌ закрыта`, и сколько длится состояние;
- модель и уровень effort (low / medium / high / xhigh / max) основной сессии;
- сколько субагентов работает прямо сейчас и на каких моделях;
- ветка и последний коммит, сколько коммитов не запушено, статус сборки на GitHub
  (GitHub Actions, а если их нет — commit statuses, например Vercel).

**Значок в названии чата** в списке чатов десктоп-приложения:

```
● Рефакторинг модуля оплаты                 ← работает
◐ Миграция базы данных                      ← ждёт разрешения
✓ Исправить поиск по каталогу               ← готов, сборка прошла
✗ Новая страница тарифов                    ← готов, сборка упала
◷ Часовой пояс в отчётах                    ← готов, идёт сборка
○ Обновить зависимости                      ← готов, сборок нет
```

Список чатов плагины не расширяют, поэтому значок ставится в начало названия; ваш текст названия
сохраняется. Переименование делается только там, где оно не спрашивает подтверждения (например, в
режиме обхода запросов разрешений или с правилом `allow` для `mcp__ccd_session_mgmt__set_session_title`
и `mcp__ccd_session_mgmt__get_session`), и только при смене статуса.

**Панель «Сессии проекта»** (`/sessions` или кнопка в строке): сессии только текущего проекта —
последний коммит, его сборка и ссылка на неё, у каждой сессии статус, модель, effort и активные агенты.

**Панель «Все проекты»** (`/sessions-all` или кнопка в панели проекта): то же по всем проектам,
сгруппированное по репозиторию.

**Строка меню macOS** (отдельное маленькое приложение из папки `menubar/`):

```
● 2  ✎ 1  ◷ 1  ✗ 1
```

- в строке — сколько чатов работает (`●`), ждёт разрешения (`◐`), и сколько задач на каждом шаге
  выкладки: `✎` не закоммичено, `⬆` закоммичено (не запушено), `◷` в процессе выкладки, `✗` ошибка;
  когда всё выложено — `✓`;
- при наведении — каждая задача с моделью и уровнем (low / medium / high / xhigh / max) и под ней
  агенты, которые над ней работают, с их моделью и уровнем:

  ```
  ● Анализ звонков
      работает · Opus 5.5 · xhigh · ✓ успешно
      ↳ Еженедельная сводка — Sonnet 5.5 · xhigh
  ```
- по клику — меню по проектам; клик по задаче открывает её чат в приложении Claude, есть ссылка
  на сборку.

Установка (собирается локально из исходника, нужен Xcode Command Line Tools):

```bash
./menubar/install.sh
```

Приложение ставится в `~/Applications/Claude Session Status.app` и запускается при входе в систему.
Удаление: `./menubar/install.sh --uninstall`.

## Установка

В терминальной сессии Claude Code:

```
/plugin install session-status --marketplace mr-Abdrahimov/claude-session-status
```

Ответьте `y` на «Add marketplace?» и выберите область user — мод заработает во всех сессиях,
включая сессии, которые запускает десктоп-приложение.

Из шелла:

```bash
claude plugin install session-status --marketplace mr-Abdrahimov/claude-session-status
```

В десктоп-приложении: «+» рядом с полем ввода → Plugins → Add marketplace `mr-Abdrahimov/claude-session-status` → Add plugin.

## Что нужно

- `git`;
- `gh`, вошедший в GitHub (`gh auth login`) — для статуса сборок. Без него мод покажет всё, кроме CI.

## Команды

- `/sessions` — сессии текущего проекта;
- `/sessions-all` — сессии всех проектов;
- `/session-band` — скрыть или показать строку над полем ввода;
- `/session-title-mark` — выключить или включить значок в названиях чатов (для всех сессий).

## Как это устроено

Каждая сессия раз в 15 секунд (и сразу при смене состояния) пишет свою запись в
`~/.claude/session-status/<id сессии>.json`; панель читает все записи. GitHub опрашивается раз в
минуту и через 5 секунд после конца каждого хода (после коммита или пуша). Сессия, которая не писала
больше 45 секунд, показывается как закрытая; записи старше 3 дней не показываются.
